Data: OpenFlights airports and routes, released under the Open Database License. The route file is a snapshot from 2014, so some routes no longer exist and newer ones are missing. Each dot is a U.S. airport with a valid IATA code, and each line means at least one airline flew directly between the two airports in either direction (international routes are removed, and the many airline-by-direction route lines are merged into one undirected edge). Dot size is the airport's degree, the number of airports it connects to directly. Panel D asks whether you can get from one airport to another with any number of connections, and counts the fewest flights needed. Code and report: course repository and report.md.
